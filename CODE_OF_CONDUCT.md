# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming, whatever someone's experience, background or language.
- No harassment, insults, personal attacks, or sexualized or discriminatory language or imagery.
- Don't publish other people's private information.
- Give and accept constructive feedback gracefully.

This applies in all project spaces: issues, pull requests, discussions and reviews.

## Enforcement

To report unacceptable behavior, open a private report through GitHub
(**Security → Report a vulnerability**, or contact a maintainer directly from their
GitHub profile). Reports are handled confidentially. Maintainers may remove content
and warn, suspend or ban contributors, following the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
